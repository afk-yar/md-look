## T-02, T-03. Лишнее из сборки — 2026-10-15

Исключены в `MDLook.spec`: numpy, cryptography, кодеки PIL (AVIF, WebP, CMS, Tk, Math, Qt).

| | До | После |
|---|---|---|
| `dist/MDLook` | 82 МБ | 35 МБ |
| `_internal/PIL` | 11 МБ | 2,5 МБ |

Почему безопасно:
- numpy в PIL нужен только функциям обмена с массивами и подсказкам типов, в `app.py` их нет.
- cryptography в pywebview нужен только для самоподписанного сертификата при `ssl=True`, MDLook его не включает.
- PIL при открытии картинки пропускает плагины, которые не удалось импортировать; .ico открывают Ico/Bmp/Png-плагины, они остались.

Проверки:
- Трей с тем же набором исключённых модулей (`E:\tmp\mdlook-timing\tray_check.py`): иконка создана, `visible: True`.
- Собранный exe стартует и отрисовывает документ: 5 прогонов на каждый файл, медианы на уровне `замер-до.md` (example 1673 мс, книга 1854 мс). Размер на скорость старта не влияет.
- Первый прогон сразу после пересборки, когда файлов ещё нет в кеше диска, — 2436 мс против 1673 по медиане. Из лишних ~0,7 с почти всё приходится на этап до первой строки `app.py` (859 мс против ~170). Это оценка того, сколько добавляет холодный диск.
- Пункты меню трея не менялись, вручную не прокликивались.

## T-04. Общая страница вместо пересборки HTML — 2026-10-15

- Шаблон с мостом пишется один раз в `%LOCALAPPDATA%\MDLook\page-cache\page-<ключ>.html`; ключ — размер и время шаблона, текст моста, режим замера. Все окна и все запуски грузят эту страницу.
- Страница помечена `window.__mdlookHost`, своего документа в ней нет; мост после запуска спрашивает `Api.initial_document()`: текущий файл окна (свежее чтение) или `example.md`. Перезагрузка страницы показывает текущий файл, а не тот, с которым окно открылось.
- Первый документ окна не стирает черновик безымянного окна (`clearAutoSave` только при смене документа).
- Попутно: раздел «папка документа» в справке теперь обновляется при смене файла в окне, раньше показывал папку первого файла.
- `build_html` остался для тестов и автономного шаблона.

Проверки: 142 теста, новые — `tests/test_host_page.py` и группа общей страницы в `tests/test_multiwindow.py`. Собранный exe: два окна через второй запуск, закрытие одного, повторное открытие — оба окна с документами; переход `--goto` при запуске и через уже запущенный экземпляр.

## T-05. KaTeX и Mermaid по требованию — 2026-10-15

- Скрипты KaTeX и Mermaid стали блоками `<script type="text/plain">`: браузер их не компилирует. `loadEmbeddedLib` выполняет библиотеку один раз, когда в документе есть формула или диаграмма.
- «Дубль CSS KaTeX» оказался копией внутри строки экспорта шаблона вместе со шрифтами Inter (1,8 МБ). Экспорт теперь берёт оба блока стилей со страницы; заодно в экспорт попали кириллические начертания Inter, которых в копии не было.
- Шаблон 7,6 → 5,8 МБ, сборка 35 → 34 МБ.

Проверки: 146 тестов, новые — `tests/test_lazy_libs.py` (документ без формул не загружает библиотеки; с формулами и диаграммой рендерит, повторный рендер не грузит их снова; экспорт шаблона содержит шрифты и CSS KaTeX). В собранном exe в WebView2 документ с формулами и диаграммой Mermaid отрисован (снимок `E:\tmp\mdlook-timing\shots\step2-0.png`). Экспорт из собранного exe вручную не проверялся: он клонирует отрисованную страницу и от загрузки библиотек не зависит.
